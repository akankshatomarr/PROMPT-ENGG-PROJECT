# SmartStudy - AI-Powered Study Plan Generator

Team PromptVerse (Team ID: PE-B13-50)

A Streamlit app that builds a day-by-day study timetable from subjects, exam dates and daily hours, and uses Gemini to write an AI study plan, practice questions and a tip for each session.

## Prototype link
https://prompt-engg-project-igyt2pmcnvtzns2bsxdqop.streamlit.app/

## How to run
pip install -r requirements.txt
python3 -m streamlit run app.py
(Add GEMINI_API_KEY in .streamlit/secrets.toml or Streamlit Secrets)
